# 单词花园 · 使用说明

一款面向初中生的英语背单词应用，覆盖**外研版（2024 新版）初中英语全六册**词汇。

- 七上 / 七下 / 八上 / 八下 / 九上 / 九下，共 **1330 个词、7980 道题**
- 按课本课时分课（每课 8~12 词），先教后考，六种题型交叉练习
- 自动错题本 + 真实记忆曲线复习 + 可爱小狗「旺仔」吉祥物陪伴

---

## 一、文件说明

| 文件 | 用途 |
|---|---|
| `WordGarden.exe` | **Windows 电脑版**（需配合同目录的 `index.html` 一起使用） |
| `index.html` | Windows 电脑版的程序数据（**必须和 exe 放同一文件夹**） |
| `WordGarden.apk` | **安卓手机版**，传到手机即可安装 |
| `dotnet-desktop-runtime-8.0.11-win-x64.exe` | **电脑版的运行环境安装包**（见下方说明） |

---

## 二、Windows 电脑版怎么用

### 第 1 步：安装运行环境（只需装一次）

双击运行 **`dotnet-desktop-runtime-8.0.11-win-x64.exe`**，一路「下一步」安装完成即可。

> 这一步是安装微软官方的 .NET 运行库（约 56MB，安全可靠）。如果这台电脑已经装过 .NET 8 桌面运行时，可跳过此步。

### 第 2 步：打开应用

把 **`WordGarden.exe`** 和 **`index.html`** 放在**同一个文件夹**里（保持文件名不变），双击 `WordGarden.exe` 即可使用。

> 注意：`index.html` 不能改名、不能删除，它是程序的"大脑"。

### 存档保存在哪？

学习进度自动保存在电脑的 `%APPDATA%\单词花园` 文件夹，**不会因为清理浏览器缓存而丢失**。

---

## 三、安卓手机版怎么用

1. 把 `WordGarden.apk` 传到手机（微信 / QQ / 数据线均可）。
2. 在手机上点击安装，如提示「未知来源」，请允许该安装。
3. 安装完成后打开即可使用，学习进度自动保存在应用私有目录（卸载前不会丢）。

---

## 四、使用流程

1. 打开应用，先**创建学生账号**（一台设备可存多个学生）。
2. 首次使用会做一次**定级测试**（6 道词义题），自动判断该从哪一册开始。
3. 进入学习后，按课时「先教后考」，学完一册自动解锁下一册。
4. 答错的词会自动进**错题本**，系统会按记忆曲线安排复习。

---

## 五、常见问题

**Q：电脑双击 exe 没反应 / 报错？**
先确认已装 .NET 运行库（第 1 步），且 `index.html` 和 exe 在同一文件夹。

**Q：学习进度会丢吗？**
电脑版存 `%APPDATA%\单词花园`，手机版存应用私有目录，都不会因清缓存而丢失。

**Q：想换电脑 / 换手机，进度能带走吗？**
应用内「设置」提供「导出存档 / 导入存档」功能，可导出 JSON 文件迁移。
